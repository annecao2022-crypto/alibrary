# Personal Library

个人全栈数字图书馆，支持书籍管理、在线预览、点赞推荐和许愿清单。

---

## 快速开始

**第一次使用：** 双击运行 `【第一步】安装依赖.bat`

**日常启动：** 双击运行 `【第二步】启动图书馆.bat`

启动后浏览器会自动打开图书馆首页。

---

## 功能说明

### 首页（用户端）

**书库浏览**
- 书籍卡片网格展示，响应式布局（2~6列）
- 按分类筛选（标签动态来自实际书籍）
- 搜索书名/作者（300ms 防抖）
- 排序：最新上传 / 书名A-Z / 随机

**封面**
- 无封面时显示渐变色背景，颜色可按分类由管理员配置
- 悬浮显示预览/下载按钮

**推荐区**
- ⭐ 馆长推荐：管理员手动指定，顶部展示
- ❤️ 心动推荐：点赞数最高的书（馆藏 + Z-Library），最多显示 4 本

**书籍操作**
- 预览：EPUB（章节阅读 + 进度记忆）、PDF（内嵌）、图片等
- 下载
- 点赞：累计计数，红心点亮后不复原

**Z-Library 集成**
- 搜索更多书籍，跳转 Z-Library 下载
- 根据馆藏自动推荐相关书籍

**许愿清单**（右下角 💌 按钮）
- 用户可留言/求书，姓名选填

---

### 管理后台（需登录）

从首页点击右上角「管理后台」进入，或直接在地址栏末尾加 `/admin`。

**📚 书籍管理**
- 批量上传（PDF / EPUB / MOBI / TXT 等），自动识别书名作者
- 编辑书名、作者、分类
- 删除书籍
- Z-Library 搜索 + 刷新首页推荐

**♥ 喜欢数据**
- 汇总展示每本书的点赞数（馆藏 / Z-Library 区分）
- 一键清空全部记录

**💌 许愿清单**
- 查看所有用户留言，显示内容、姓名、日期

**⚙️ 网站设置**
- 网站标题 / 副标题
- 公告栏
- 书库简介
- 主题色
- 首页默认排序
- 分类封面颜色映射（每个分类选对应渐变色）
- 馆长推荐书目（最多 6 本）
- Z-Library 账号配置

---

## 技术栈

- **后端**：FastAPI + SQLAlchemy + SQLite
- **前端**：React 18 + Vite + Tailwind CSS
- **认证**：JWT（管理员）
